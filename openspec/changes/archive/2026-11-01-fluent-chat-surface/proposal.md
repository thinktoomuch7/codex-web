# Proposal

## Why

现在的页面把项目表单、策略下拉和 Git 按钮摊在对话前面，生成时又把整段记录反复传给浏览器，所以又难用又卡。操作者要的是官方 Codex 对话那种直接接着说的界面，同时吸收自托管项目里把控件藏起来、让手机和长对话仍然跟得上的做法。

## What Changes

- **BREAKING** 默认侧栏不再是「先选项目再看该项目的会话」。它是一条跨已登记项目的「最近」列表，按最近活动排列，不按日期分组。每一行是短标题加项目名。
- 主列只留标题和对话。用户的话靠右，助手正文是普通段落。命令、文件变更和审批收在可展开的检查项里，并显示这一轮用了多久。未展开时不把命令输出画进页面。
- 输入框是唯一常驻的操作。进行中时发送变为停止，且只停当前会话。模型、沙箱、审批和查找放在一张按需打开的设置里。改名、归档、分叉、删除放在该会话自己的菜单里。diff、暂存、还原、提交、推送和 pull request 放在按需打开的审查里。
- 登记项目、新会话写到单独 worktree 还是当前目录，从侧栏底部的加号进入。网页密码、目录必须已经存在，这些约束不变，只是不再占住侧栏。
- 正文增量只追加新出现的片段。生成过程中不因为每个字重新读取整份时间线、会话列表、Git 或模型列表。很长的对话只绘制最近的一段。
- 定时任务、资料库、插件、探索、分享、语音、内嵌终端、文件编辑器和命令面板不做。没有的功能不放空入口。
- 多条会话仍可同时执行。同一条会话一次一轮，下一句排队。正在执行或等待审批时不能删除。这些执行规则不在本变更里改写。

## Capabilities

### New Capabilities

- 无。

### Modified Capabilities

- `workspace-ui`: 工作区从控制台式布局改成官方对话架子。最近列表跨项目，工具按需打开，生成时只追加新文字。
- `codex-gateway`: 提供跨项目的最近会话列表。文本增量只携带新片段，且不为每个片段重读时间线或会话列表。

## Impact

- `web/src/App.tsx` 和 `web/src/workspace.css` 重排侧栏、对话和输入框。现有的项目下拉、常驻 Git 区和策略下拉不再作为默认画面。
- 网关增加一个最近会话的读取。现有的按项目列表仍可供登记和归档使用。文本事件流保持小片段，避免退回整份时间线。
- 主规格里的 `codex-gateway` 仍写着「全机同时只跑一个 turn」。运行中的系统已经按 `align-codex-app` 改成按会话互斥。本变更不恢复那把全局锁，也不在这里重写那条执行规格。
- 不改网页登录、监听端口、对外地址，不把 Codex 放回 80 端口，也不依赖任何社区 Codex Web 项目的代码。
